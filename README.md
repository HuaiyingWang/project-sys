# Project Desk 接案專案管理

單一 HTML 檔案的接案專案管理工具，無需後端、無需建置流程，資料全部存在瀏覽器的 IndexedDB。

## 功能

- **專案列表**：搜尋、依狀態篩選、多種排序方式（最近更新／建立日期／維護到期日／名稱／業務／待辦需求數）
- **專案基本資料**：狀態、業務、聯絡窗口、上線／到期日等
- **技術資訊**：正式網域、測試站、後台網址、主機、FTP 資訊
- **需求紀錄時間軸**：記錄每筆需求內容、來源窗口、完成狀態
  - 支援貼上、拖放或選擇上傳**圖片**
  - 支援上傳**任何格式的檔案**（PDF、Word、zip 等）
  - 圖片、PDF、純文字檔（.txt/.md/.json/.csv/.log/.yml/.yaml/.xml）可直接在彈窗預覽；其他格式提供下載
- **聯絡窗口管理**：可複用於多個專案
- **備份與還原**：JSON 完整備份（含圖片與檔案），或 Markdown 匯出入（純文字，不含附件內容）
- **GitHub Pages**：已設定部署

## 技術棧

- Vanilla JS（無框架）、單一 `index.html`
- IndexedDB 儲存專案、需求、聯絡窗口、圖片與檔案
